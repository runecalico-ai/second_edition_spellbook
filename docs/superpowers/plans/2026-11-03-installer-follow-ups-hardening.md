# Installer Follow-ups Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the Low follow-ups left by the `add-cross-platform-installers` local release verification: tighten webview IPC and add a CSP, clean `clippy --all-targets`, upgrade older vaults (blob-backed `spell_vec`, pre-fix embedding vectors), delete orphaned spell files on delete, document the permissions file, and keep Tauri's `test` feature out of release builds.

**Architecture:** Each follow-up is a small, independently testable change in the Tauri backend (`apps/desktop/src-tauri`) or its config. Vault upgrades run at startup: `init_db` repairs a blob-backed `spell_vec` once sqlite-vec loads, and the embeddings startup backfill forces one full reindex when the recorded embedding-model revision does not match the approved MiniLM revision. Security config is verified by Rust ACL tests and one new Playwright spec that runs against the built frontend.

**Tech Stack:** Rust (Tauri 2.9.5, rusqlite 0.31 bundled, sqlite-vec 0.1.6, fastembed =5.13.3), Tauri capabilities/ACL, Tauri CSP injection, Playwright (CDP to WebView2), PowerShell on Windows.

```markdown
### Webview permissions (capabilities)
App commands registered in `invoke_handler` need no permission. Core and plugin JS APIs do: `@tauri-apps/api/event` (`listen`), `@tauri-apps/plugin-dialog`, `@tauri-apps/plugin-fs`, window/webview APIs, and so on. - Consumes: Playwright fixtures `test`/`expect` from `tests/fixtures/test-fixtures`, `TIMEOUTS` from `tests/fixtures/constants`, nav test ids `nav-link-library`, `nav-link-characters`, `nav-link-import`, `nav-link-chat`, `nav-link-export`, `settings-gear-button`.
```
- Produces: built assets (release and `tauri build --debug`) are served with:

```text
default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self' data:; connect-src 'self' ipc: http://ipc.localhost; object-src 'none'; base-uri 'self'; form-action 'self'
```

Notes that shape this policy (Tauri 2.9.5 source, `tauri-codegen` `context.rs` and `tauri` `manager/mod.rs`):
- Tauri hashes inline `<script>` blocks in `dist/index.html` and adds them to `script-src`, so the theme bootstrap script in `index.html` keeps running without `'unsafe-inline'`.
- Tauri only adds a `style-src` nonce/hash when assets contain inline styles; ours do not, so `'unsafe-inline'` stays effective. It is needed for Playwright `page.addStyleTag` in `spell_editor_visual.spec.ts`. React `style={}` props use CSSOM and are not affected.
- `connect-src` must allow Tauri IPC: `ipc:` (Linux/macOS) and `http://ipc.localhost` (Windows).
- `img-src data:` covers CSS data-URI icons.
- In `tauri dev` the page comes from the Vite server, not Tauri's asset protocol, so this CSP is not injected there.

```ts
import { TIMEOUTS } from "./fixtures/constants";
import { expect, test } from "./fixtures/test-fixtures";

const NAV_TEST_IDS = [
  "nav-link-library",
  "nav-link-characters",
  "nav-link-import",
  "nav-link-chat",
  "nav-link-export",
] as const;

test.describe("Content Security Policy", () => {
  test("built app enforces CSP without blocking its own UI", async ({ appContext }) => {
    const { page } = appContext;

    await test.step("Setup: collect CSP violations from first paint", async () => {
      await page.addInitScript(() => {
        window.__SPELLBOOK_E2E_CSP_VIOLATIONS__ = [];
        document.addEventListener("securitypolicyviolation", (event) => {
          window.__SPELLBOOK_E2E_CSP_VIOLATIONS__?.push(
            `${event.violatedDirective} ${event.blockedURI}`,
          );
        });
      });
      await page.reload();
      await expect(page.getByTestId("nav-link-library")).toBeVisible({ timeout: TIMEOUTS.long });
    });

    await test.step("Verify: CSP is active", async () => {
      const evalOutcome = await page.evaluate(() => {
        try {
          // biome-ignore lint/security/noGlobalEval: probes that the CSP blocks string evaluation
          eval("1");
          return "allowed";
        } catch (error) {
          return error instanceof Error ? error.name : String(error);
        }
      });
      expect(evalOutcome).toBe("EvalError");
    });

    await test.step("Action: visit every main screen", async () => {
      for (const testId of NAV_TEST_IDS) {
        await page.getByTestId(testId).click();
        await page.waitForTimeout(500);
      }
      await page.getByTestId("settings-gear-button").click();
      await expect(page.getByRole("heading", { name: "Settings" })).toBeVisible({
        timeout: TIMEOUTS.medium,
      });
    });

    await test.step("Verify: inline theme script ran and nothing was blocked", async () => {
      await expect(page.locator("html")).toHaveAttribute("data-theme", /^(light|dark)$/);
      const violations = await page.evaluate(() => window.__SPELLBOOK_E2E_CSP_VIOLATIONS__ ?? []);
      expect(violations).toEqual([]);
    });
  });
});
```

```rust
/// Rebuilds a blob-backed `spell_vec` as a sqlite-vec `vec0` table once the
/// extension is loaded on this connection. Returns `Ok(true)` when it rebuilt.
/// Vectors are derived data; the embeddings startup backfill repopulates them.
pub fn repair_blob_backed_spell_vec(conn: &Connection) -> Result<bool, AppError> {
    let table_exists = conn
        .query_row(
            "SELECT 1 FROM sqlite_master WHERE type = 'table' AND name = 'spell_vec'",
            [],
            |_| Ok(()),
        )
        .optional()?
        .is_some();
    if !table_exists || crate::db::spell_vec_is_vec0(conn) {
        return Ok(false);
    }
    if conn
        .query_row("SELECT vec_version()", [], |row| row.get::<_, String>(0))
        .is_err()
    {
        return Ok(false);
    }

    let tx = conn.unchecked_transaction()?;
    tx.execute_batch(
        "DROP TABLE spell_vec;
         CREATE VIRTUAL TABLE spell_vec USING vec0(
           rowid INTEGER PRIMARY KEY,
           v float[384]
         );",
    )?;
    tx.commit()?;
    warn!("sqlite-vec: rebuilt blob-backed spell_vec as vec0; embeddings will be reindexed");
    Ok(true)
}
```

```rust
pub(crate) fn is_content_hash_live(
    conn: &rusqlite::Connection,
    content_hash: &str,
) -> Result<bool, AppError> {
    use rusqlite::OptionalExtension;

    let referenced = |sql: &str| -> Result<bool, AppError> {
        Ok(conn
            .query_row(sql, [content_hash], |_| Ok(()))
            .optional()?
            .is_some())
    };

    if referenced("SELECT 1 FROM spell WHERE content_hash = ?1 LIMIT 1")? {
        return Ok(true);
    }
    if crate::db::table_has_column(conn, "artifact", "spell_content_hash")
        && referenced("SELECT 1 FROM artifact WHERE spell_content_hash = ?1 LIMIT 1")?
    {
        return Ok(true);
    }
    if crate::db::table_has_column(conn, "character_class_spell", "spell_content_hash")
        && referenced("SELECT 1 FROM character_class_spell WHERE spell_content_hash = ?1 LIMIT 1")?
    {
        return Ok(true);
    }
    Ok(false)
}
```

```rust
pub(crate) fn delete_spell_with_conn(
    conn: &Connection,
    vault_root: &std::path::Path,
    maintenance: &VaultMaintenanceState,
    id: i64,
) -> Result<(), AppError> {
    let content_hash: Option<String> = conn
        .query_row("SELECT content_hash FROM spell WHERE id = ?1", [id], |row| {
            row.get::<_, Option<String>>(0)
        })
        .optional()?
        .flatten();

    conn.execute("DELETE FROM spell_vec WHERE rowid = ?", [id])?;
    conn.execute("DELETE FROM spell WHERE id = ?", [id])?;

    let Some(hash) = content_hash else {
        return Ok(());
    };
    if is_content_hash_live(conn, &hash)? {
        return Ok(());
    }
    let Ok(_gc_guard) = maintenance.start_gc() else {
        tracing::info!(%hash, "vault maintenance busy; leaving spell file for deferred GC");
        return Ok(());
    };

    let path = spell_file_path_in_root(vault_root, &hash);
    match std::fs::remove_file(&path) {
        Ok(()) => {}
        Err(error) if error.kind() == std::io::ErrorKind::NotFound => {}
        Err(error) => {
            tracing::warn!(path = %path.display(), %error, "failed to remove deleted spell's vault file; deferred GC will retry");
        }
    }
    Ok(())
}
```

```rust
#[tauri::command]
pub async fn delete_spell(
    state: State<'_, Arc<Pool>>,
    embedding_state: State<'_, Arc<EmbeddingState>>,
    maintenance_state: State<'_, Arc<VaultMaintenanceState>>,
    id: i64,
) -> Result<(), AppError> {
    cancel_spell_embedding_for_delete(embedding_state.inner().as_ref(), id);
    let pool = state.inner().clone();
    let maintenance_state = maintenance_state.inner().clone();
    tokio::task::spawn_blocking(move || {
        let conn = pool.get()?;
        let vault_root = crate::db::app_data_dir()?;
        delete_spell_with_conn(&conn, &vault_root, maintenance_state.as_ref(), id)
    })
    .await
    .map_err(|e| AppError::Unknown(e.to_string()))??;

    Ok(())
}
```
